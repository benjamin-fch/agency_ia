# Prompt — Réécriture homepage

## Usage
Générer les textes conversion-first d'une homepage pour un client B2B.

---

## Prompt IA — Réécriture complète homepage

```
Tu es copywriter spécialisé en conversion web B2B. Tu ne fais pas de design, uniquement des textes.

Tu vas réécrire les textes de la homepage pour l'entreprise suivante.

INFORMATIONS OBLIGATOIRES :
- Entreprise : {{ENTREPRISE}}
- Secteur : {{SECTEUR}}
- Offre principale : {{OFFRE_PRINCIPALE}} (en 1 ligne)
- Cible principale : {{CIBLE}} (poste, taille d'entreprise, problème)
- Problème résolu (en termes client, pas en termes produit) : {{PROBLEME_RESOLU}}
- Résultat concret obtenu par les clients : {{RESULTAT_CONCRET}}
- Différenciateur principal (ce que les concurrents ne font pas) : {{DIFFERENCIATEUR}}
- Ton souhaité : {{TON}} (ex: expert direct, rassurant, pragmatique)
- Ce qu'ils détestent dans les agences/prestataires habituels : {{PAIN_CONCURRENTS}}
- 2-3 clients ou cas concrets (si disponibles) : {{CAS_CLIENTS}}
- Objections fréquentes des prospects : {{OBJECTIONS}}

SECTIONS À RÉDIGER :

**SECTION HERO**
- Titre H1 (< 10 mots, promesse de résultat ou statement fort — pas descriptif)
- Sous-titre (1-2 lignes, développe le titre en précisant pour qui et comment)
- CTA principal (3-5 mots, verbe d'action + bénéfice)
- CTA secondaire si pertinent (lien "voir comment ça marche" ou "voir nos cas clients")

**SECTION PROBLÈME**
- Titre de section (< 8 mots)
- 2-3 paragraphes ou bullet points décrivant le problème du point de vue du client
- Pas de "beaucoup d'entreprises" — parler directement au lecteur

**SECTION SOLUTION**
- Titre de section
- Description de l'approche en 3-4 phrases
- Ce qui nous rend différents (1-2 phrases précises)

**SECTION OFFRES** (résumé, pas détail)
- Pour chaque offre : titre + 2 lignes + CTA
- Ne pas lister les features — décrire ce que le client obtient

**SECTION PREUVE**
- Titres de témoignages (si disponibles, sinon laisser placeholder)
- 1-2 lignes de preuve chiffrée ou qualitative
- Logos ou mentions (si disponibles)

**SECTION CTA FINAL**
- Titre accrocheur (< 8 mots)
- 1 phrase d'appel
- CTA principal (reprendre celui du hero ou variante)

RÈGLES STRICTES :
- Pas de "nous sommes passionnés par"
- Pas de "dans un monde où"
- Pas d'adjectifs empilés sans preuve ("innovant, agile, performant")
- Le lecteur doit comprendre en 10 secondes ce que l'entreprise fait et pour qui
- Chaque section doit s'adresser directement au lecteur ("vous" pas "les entreprises")
- Les bénéfices avant les features
- La preuve doit être spécifique (pas "de nombreux clients satisfaits")

FORMAT DE RÉPONSE :
Produire un document structuré avec les titres de sections clairement marqués,
prêt à être copié dans Google Docs.
```

---

## Prompt IA — Titre H1 seul (itération rapide)

```
Génère 5 variantes de titre H1 pour la homepage de {{ENTREPRISE}}.

Contexte : {{OFFRE}} pour {{CIBLE}}, résultat : {{RESULTAT}}.

Règles :
- < 10 mots
- Orienté résultat ou problème résolu
- Pas de jargon
- Pas de question rhétorique
- Variantes : 1 direct, 1 centré problème, 1 centré résultat, 1 différenciateur, 1 inattendu

Format : Liste numérotée avec 1 ligne d'explication pour chacun.
```
