# Prompt — Email / message d'outreach

## Usage
Générer un premier message de prospection sortante pour LinkedIn ou email froid.

---

## Prompt IA — Outreach LinkedIn

```
Tu es un expert en prospection B2B directe pour une agence de contenu et conversion web.

Rédige un message de connexion LinkedIn COURT (< 300 caractères pour la note de connexion)
et un premier message de prospection (< 150 mots) pour le prospect suivant.

INFORMATIONS SUR LE PROSPECT :
- Nom / Prénom : {{NOM_PROSPECT}}
- Poste : {{POSTE}}
- Entreprise : {{ENTREPRISE}}
- Secteur : {{SECTEUR}}
- Observation spécifique (post récent, actualité, problème visible sur leur site/LinkedIn) : {{OBSERVATION_SPECIFIQUE}}

RÈGLES STRICTES :
- Ne pas mentionner l'IA dans le message
- Ne pas pitcher dans le premier message — seulement ouvrir une conversation
- L'observation spécifique doit être authentique et non générique
- Ton : direct, professionnel, humain
- Pas de "j'espère que vous allez bien"
- Pas de "je me permets de vous contacter"
- Commencer par l'observation ou la question, pas par se présenter
- Se présenter seulement si demandé ou dans le message de suivi

FORMAT DE RÉPONSE :
Note de connexion (< 300 caractères) :
[texte]

Premier message post-connexion (< 150 mots) :
[texte]
```

---

## Prompt IA — Email froid

```
Tu es un expert en prospection B2B par email.

Rédige un email froid de prospection pour le prospect suivant.
L'email doit donner envie de répondre, pas de vendre.

INFORMATIONS :
- Destinataire : {{NOM}}, {{POSTE}} chez {{ENTREPRISE}}
- Secteur : {{SECTEUR}}
- Problème observé (site, contenu, visibilité) : {{PROBLEME_OBSERVE}}
- Offre pertinente : {{OFFRE_ENVISAGEE}} (Content Engine ou Website Upgrade)

RÈGLES :
- Objet : < 50 caractères, factuel, pas de promesse
- Corps : < 150 mots
- Pas de formalité excessive
- L'ouverture parle d'eux, pas de nous
- Une seule question en clôture, ouverte et à faible friction ("Est-ce un sujet d'actualité pour vous ?")
- Signature simple : prénom, nom, agence, site

FORMAT :
Objet : [texte]
Corps : [texte]
```

---

## Exemples d'observations spécifiques de qualité

Bonnes observations (spécifiques) :
- "Votre article sur [sujet] de la semaine dernière avait un angle que je n'avais pas vu ailleurs — vous parlez à [type de cible] de façon très directe."
- "J'ai regardé votre homepage — la proposition de valeur est forte mais elle n'apparaît pas avant le fold sur mobile."
- "Vous avez posté [X] fois ce mois-ci sur LinkedIn mais j'ai noté que les posts sur [sujet] performent 3x mieux que les autres."

Mauvaises observations (génériques) :
- "Votre entreprise semble avoir beaucoup de potentiel." ❌
- "J'ai regardé votre profil et je pense qu'on pourrait travailler ensemble." ❌
- "Dans un secteur aussi concurrentiel, il est essentiel d'avoir une présence digitale forte." ❌
