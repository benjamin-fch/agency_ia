# Checklist version vendable — 30 jours

## Objectif
Passer d'un MVP fonctionnel à un système crédible et compétitif.

---

## Semaine 2 (J8–J14) — Première traction commerciale

- [ ] Conduire 5 calls de qualification minimum
- [ ] Envoyer 2 propositions commerciales réelles
- [ ] Obtenir 1 premier feedback détaillé sur le site ou les offres (prospect, ami, client potentiel)
- [ ] Adapter le positionnement si un frein récurrent est identifié pendant les calls
- [ ] Importer et tester le workflow `03-onboarding.json`
- [ ] Importer et tester le workflow `05-production-contenu.json` (génération plan mensuel)

---

## Semaine 3 (J15–J21) — Premier client ou premier feedback fort

Objectif minimum : 1 client signé OU 3 propositions envoyées avec des retours exploitables.

- [ ] Signer le premier client (quelle que soit l'offre)
- [ ] Conduire le call d'onboarding et remplir le brief complet (`templates/content/brief-contenu.md`)
- [ ] Créer le dossier client Google Drive
- [ ] Lancer la production du premier mois de contenu
- [ ] Appliquer la checklist QA sur les premiers livrables
- [ ] Livrer et recueillir le premier feedback client

---

## Semaine 4 (J22–J30) — Consolidation

- [ ] Obtenir le premier témoignage client (même informel) à intégrer dans le site
- [ ] Mettre à jour `cas-usage.html` avec un cas réel (anonymisé si nécessaire)
- [ ] Identifier les 2-3 frictions les plus fréquentes (dans les calls, dans la production, dans la livraison)
- [ ] Corriger ces frictions (adapter le brief, le template, le prompt ou le workflow)
- [ ] Écrire le premier article de blog de l'agence (sur votre propre site — mange ta propre cuisine)
- [ ] Publier 3 posts LinkedIn sur le compte de l'agence ou votre compte personnel

---

## Infrastructure à consolider avant le J30

- [ ] n8n auto-hébergé sur VPS propre (si pas encore fait, sortir de n8n.cloud)
- [ ] Backup hebdomadaire des workflows n8n configuré
- [ ] Domaine personnalisé avec HTTPS sur le site
- [ ] Google Drive structuré avec le dossier `Livrables/`
- [ ] Politique de secrets revue (toutes les clés dans variables d'environnement, `.env` hors git)
- [ ] Au moins 3 workflows n8n opérationnels

---

## Métriques à suivre à J30

| Métrique | Cible |
|---|---|
| Calls de qualification réalisés | ≥ 8 |
| Propositions envoyées | ≥ 3 |
| Taux de conversion call → proposition | ≥ 60% |
| Clients signés | ≥ 1 |
| NPS client (premier feedback) | > 7/10 |
| Site : taux de rebond | < 65% |
| Leads via formulaire | ≥ 3 |

---

## Définition du "vendable" à J30

✅ Un client est servi et satisfait
✅ Le process de vente est testé bout-en-bout
✅ La production de contenu est semi-automatisée et validée
✅ Les livrables sont dans Google Docs, propres, livrés à temps
✅ Vous pouvez expliquer l'offre en 60 secondes à un prospect froid
✅ Vous avez une preuve sociale (même minime) sur le site
