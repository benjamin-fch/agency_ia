# Standard SEO/AEO/GEO — Agency IA

## SEO on-page (standard minimal)

### Structure de page
- [ ] Un seul H1 par page, contenant le mot-clé principal
- [ ] H1 < 60 caractères
- [ ] H2 : sous-sujets naturels de la requête principale
- [ ] H3 : détails, exemples, FAQ
- [ ] Meta title : 50-60 caractères, mot-clé en début, nom de l'entreprise en fin
- [ ] Meta description : 140-160 caractères, incitative, avec mot-clé

### Contenu
- [ ] Mot-clé principal dans le premier paragraphe (naturellement)
- [ ] Densité mot-clé : pas d'objectif de densité — écrire pour le lecteur
- [ ] Champs sémantiques connexes couverts (synonymes, termes associés)
- [ ] Longueur adaptée à l'intention : informationnelle > 800 mots, commerciale 300-600 mots
- [ ] Pas de contenu dupliqué entre pages

### Liens
- [ ] Au moins 1-2 liens internes vers des pages pertinentes du même site
- [ ] Textes d'ancres descriptifs (pas "cliquez ici")
- [ ] Liens externes vers sources crédibles si des stats sont citées

### Images (si présentes)
- [ ] Attribut alt descriptif sur toutes les images
- [ ] Nommage fichiers : `mot-cle-descriptif.jpg` (pas `IMG_1234.jpg`)
- [ ] Images compressées (< 200ko pour web)

## AEO — Answer Engine Optimization

L'AEO prépare le contenu à être cité comme réponse directe par les moteurs (Google Featured Snippets, SGE, Perplexity, etc.).

### Techniques
- Formuler les H2 comme des questions réelles que pose votre audience ("Comment choisir un cabinet de recrutement B2B ?")
- Répondre directement sous chaque H2 en 2-3 phrases avant d'approfondir
- Inclure une section FAQ à la fin des articles
- Utiliser des listes et tableaux quand pertinent (mieux indexés)
- Définir clairement les termes clés du secteur en début d'article

### Format idéal pour les featured snippets
```
[Question comme H2]
[Réponse directe en 40-60 mots dans le premier paragraphe]
[Développement ensuite]
```

## GEO — Generative Engine Optimization

Le GEO prépare le contenu à être cité par les LLMs (ChatGPT, Claude, Gemini) dans leurs réponses.

### Principes
- **Autorité factuelles** : inclure des données vérifiables, des chiffres sourcés, des dates
- **Attribution claire** : "Selon [source crédible]..." — les LLMs préfèrent les contenus qui citent des sources
- **Structure explicite** : titres clairs, paragraphes distincts, pas d'ambiguïté
- **Contexte géographique** : mentionner la localisation quand pertinent (important pour les PMEs locales)
- **Originalité** : éviter de paraphraser du contenu existant — apporter un angle ou une donnée nouvelle

### Ce qui aide le GEO
- Pages "À propos" détaillées avec expertise réelle de l'équipe
- Témoignages clients avec noms et entreprises réels
- Études de cas avec résultats chiffrés
- Pages FAQ bien structurées
- Mentions dans la presse ou sur d'autres sites (backlinks = signal de crédibilité)

## Ce que nous ne promettons pas

- Aucune garantie de position dans les SERP
- Les résultats SEO prennent 3 à 6 mois minimum
- Nous optimisons le contenu — pas l'infrastructure technique (vitesse, Core Web Vitals) sauf si inclus dans le scope
