# Checklist qualité — Agency IA

Passer cette checklist sur chaque livrable avant envoi client.
Si un point est rouge → ne pas livrer, corriger d'abord.

---

## Fond

- [ ] Le livrable répond à l'objectif défini dans le brief
- [ ] Chaque affirmation factuelle est vérifiée (chiffres, dates, noms propres)
- [ ] Aucun placeholder non remplacé ([NOM], [DATE], [INSÉRER ICI])
- [ ] La valeur pour le lecteur est explicite, pas implicite
- [ ] Aucune information potentiellement fausse ou non vérifiable

## Forme

- [ ] Pas de faute d'orthographe (vérifier avec LanguageTool ou Antidote)
- [ ] Pas de faute de grammaire ou de syntaxe
- [ ] Ponctuation cohérente sur tout le document
- [ ] Paragraphes courts (max 5 lignes pour web/LinkedIn)
- [ ] Pas de répétition de mot-clé à moins de 3 lignes d'intervalle

## Cohérence

- [ ] Ton homogène du début à la fin
- [ ] Nom du client et noms propres corrects
- [ ] Pas de mélange "tu/vous" non intentionnel

## Anti-générique IA (voir `docs/qa/anti-generique-ia.md`)

- [ ] Pas de "Dans un monde où…"
- [ ] Pas de "Il est essentiel de…"
- [ ] Pas de triades d'adjectifs sans preuve ("innovant, agile, performant")
- [ ] Chaque affirmation peut être rattachée à un exemple concret du secteur client
- [ ] Le contenu ne pourrait pas être posté tel quel par un concurrent direct

## Conversion (pages web et contenus commerciaux uniquement)

- [ ] Un seul CTA principal identifié et clairement formulé
- [ ] Les bénéfices sont du point de vue client ("vous obtenez X"), pas agence ("nous faisons X")
- [ ] La preuve sociale est spécifique (pas "de nombreux clients satisfaits")
